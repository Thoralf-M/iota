# Multisig CLI-commands to manage the regulated coin package

This document shows the steps for publishing a package with a multisig address, but the same steps with `--serialize-unsigned-transaction` can be used for any transaction.

## Publish the package

Prepare publisher:

```shell
# make sure to be on the right network
iota client switch --env devnet

# doesn't work on mainnet, manually send funds from another account to the address
iota client faucet --address $MULTISIGADDRESS
# wait for funds to arrive
sleep 5
```

```shell
cd iota/examples/move/regulated-coin/packages
TX_DATA=$(iota client publish regulated_coin --serialize-unsigned-transaction)
echo "TX_DATA: $TX_DATA"
```
2 signatures are required, for this example we can just generate them on the same machine.
```shell
SIG1=$(iota keytool sign --address Address0ForMultiSig --data $TX_DATA --json | jq -r '.iotaSignature')
echo "SIG1: $SIG1"
SIG2=$(iota keytool sign --address Address1ForMultiSig --data $TX_DATA --json | jq -r '.iotaSignature')
echo "SIG2: $SIG2"
```

Combine the signatures:
```shell
COMBINED_SIG=$(iota keytool multi-sig-combine-partial-sig \
--pks $ADDRESS0 $ADDRESS1 $ADDRESS2 \
--weights 1 1 1 \
--threshold 2 \
--sigs \
$SIG0 \
$SIG1 \
--json | jq -r '.multisigSerialized')
echo "COMBINED_SIG: $COMBINED_SIG"
```

Finally execute the transaction:
```shell
iota client execute-signed-tx --tx-bytes $TX_DATA --signatures $COMBINED_SIG
```
